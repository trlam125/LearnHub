# LearnHub

**LearnHub** is an online learning platform for English and Chinese, designed to provide an interactive and accessible learning experience.

## Features

- English and Chinese courses
- Interactive lessons and quizzes
- Vocabulary learning and flashcards
- Learning progress tracking
- User accounts and personal dashboards
- Course and content management
- Online enrollment and payment support

## Technology

Built with Java, Spring Boot, Thymeleaf, and MySQL.
